# DDF — Dioli Dropshipping Factory

## Blueprint funcional oficial para Control Room

Este diretório é uma especificação NOVA e isolada. O MVP/código legado existente no repositório não define a arquitetura da DDF e não deve ser misturado ou reutilizado por conveniência. A Control Room deve tratar `DDF-BLUEPRINT/` como fonte funcional do novo projeto.

## Missão
Construir uma Factory multiforncedor e multicanal que descubra oportunidades, mantenha candidatos baratos até aprovação, industrialize digitalmente produtos aprovados em um cadastro mestre extremamente rico, proteja margem, distribua para qualquer canal suportado e transforme vendas em inteligência de decisão.

Define estrutura, objetivos, fluxos, contratos funcionais, regras e salvaguardas. Não define identidade visual e deliberadamente não escolhe agentes/modelos de IA; isso será decidido dentro da Control Room.
